# Change log — {{PROJECT}}

Record of **what** we changed, **why**, and **which version shipped it**.
Commits tell *how*; this log tells *why*.

## Layout

```
{{DIR}}/
├── README.md            ← this index
├── entry-template.md    ← template for new entries
├── entries/             ← one per branch / PR
│   └── YYYY-MM-DD-<type>-<topic>.md
└── releases/            ← one per published version (generated by the release)
    └── vX.Y.Z.md
```

## Rules

1. Every branch that gets merged has **one** entry. No entry, no PR.
2. One branch = one entry = one owner. If the branch grows, update the same entry.
3. `version` starts as `unreleased` and is **never** edited by hand: the release sets it.
4. Released entries are not rewritten (typos only). If something changes, write a new entry.
5. No secrets, tokens, private URLs or real personal data.

Types (same prefixes as commits): `feat`, `fix`, `chore`, `docs`, `refactor`, `perf`, `test`.
